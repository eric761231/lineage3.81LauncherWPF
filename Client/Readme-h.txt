Lineage

Lineage is a RPG style multi user online game. It is based on the comics
"Lineage" written & drawn by Ilsook Shin. Theme is a medival fantasy.

You can get most recent version from http://www.lineagechina.com

System Requirement
------------------
	- Window 95, 98 or Windows NT 4.0 SP3, Windows XP
	- Pentium 75MHz or higher
	- Main memory 16M or higher
	- Video card supports 640x480x16bpp
	- Internet connection (modem or LAN)

Installation
------------
	Install DirectX first.
	   You can get it from http://www.microsoft.com/


	Run downloaded Setup.exe, it will install files to
	your system.

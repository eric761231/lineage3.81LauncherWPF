Lineage

Lineage is a massively multiplayer online role-playing game (MMORPG).
Theme is a medival fantasy.

You can get most recent version of Lineage from
http://lineagethebloodpledge.com

System Requirement
------------------
	- Window 95, 98, ME, Windows NT 4.0 SP3 or Windows 2000
	- Pentium II 350MHz or higher
	- Main memory 128M or higher
	- Video card supports 640x480x16bpp
	- Internet connection (modem or LAN)
	- More than 900MB Hard Disk Space

Installation
------------
	Install DirectX if you do not have it installed already.
	You can get it from http://www.microsoft.com/ or
	http://lineagethebloodpledge.com

To install the game run downloaded linXXXX.exe, it will install the game
on your system. Once Lineage is installed, you can get a free trial
account from http://lineagethebloodpledge.com

If you experience any problems please email support@ncinteractive.com
for assistance.

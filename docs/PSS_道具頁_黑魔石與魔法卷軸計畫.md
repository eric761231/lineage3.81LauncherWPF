## 3. 勾選疊加（第 5 點）

**勾選＝要自動提煉「這一格的石頭」（消耗該級，產下一級）。**  
不是「目標只要四級就從一級一路煉上來」的隱含連鎖——沒勾的等級跳過。

### 3.1 規則

每 tick **只煉 1 顆**。由低到高掃勾選：

1. 只勾一格：只處理那一級。  
   - 只勾一級 → 有 40320 就煉成二級。  
   - 只勾四級 → 有 40323 才煉；背包只有一級／二級／三級**不會**自動幫你煉到四級。
2. 勾兩格（或以上）：**依序**（格 0→1→2→3）。本 tick 先試最低已勾且背包有貨的那一級；沒貨才試下一勾。  
   - 勾一級＋二級：先煉 40320；沒有一級才煉 40321。  
   - 勾一級＋四級：先煉一級；沒有一級才煉四級（中間二、三級沒勾就不煉）。
3. 四格全沒勾：停 timer，什麼都不做。
4. 沒學技能 100（`isSkillMastery(BRING_STONE)`）、MP 不足、沒有對應石頭：本 tick 略過該級，不洗頻訊息。

這樣「疊加」是**多個獨立開關依序排隊**，不是高勾選自動包含低勾選。

### 3.2 後端怎麼跑

- 獨立 `DarkStoneTimer`（約 1.2s），對齊吃肉：跟 overlay 開不開、喝水「啟動」無關。
- 真正提煉呼叫既有 `Skill_100.run(pc, itemObjId, …)`（含動畫／失敗 280／成功 403），PSS 只負責找背包 `findItemId(40320+grade)`、扣 MP（`L1Skills.getMpConsume()`）、確認已學會。
- 登出：`DarkStoneTimer.stop` 再 `state.clear()`（與其他 pssTimer 同一處）。

### 3.3 封包

不要加長 0x5A。另用 **128 magic `0x5C`**，整包仍 **4 bytes**（opcode＋magic＋flags＋pad，≠ 城堡 5）：

| bit | 意義 |
|---|---|
| 0 | 勾一級（煉 40320） |
| 1 | 勾二級（煉 40321） |
| 2 | 勾三級 |
| 3 | 勾四級 |
| 4～7 | 預留（之後卷軸總開關可放 bit4，這輪送 0） |

`C_SecurityStatus`：length≠5 且 magic 0x5C → `applyDarkStoneFlags` → `DarkStoneTimer.sync`。不明 magic 仍直接 return，不要開 CastleS。

本機 cfg：`craft.darkStone0`～`craft.darkStone3`（0/1）。開面板／QueueSave 跟 0x5A 分開送，仍走 `g_inPump` 禁止重入。

## 4. 製作魔法卷軸（這輪只定入口）

現有 NPC 流程在 `L1NpcSet.doCreateMagicScroll`／`Npc_MagicBuff`：

- 空卷：`40089 + skillLevel`（lv1～5 → 40090～40094）
- 金幣：`{0, 500, 1000, 1000, 2000, 2000}[skillLevel] × 數量`
- 額外材料：該技能 `itemConsumeId / itemConsumeCount`
- 產物：`40858 + skillId`（cmd A～Y 對應固定 25 個 skillId）

自動做卷需要「做哪幾個技能＋每次數量」。技能欄點選還沒接（BUFF 右上同一前置），這輪：

1. 右下畫出區域與空格，避免之後再拆版面。  
2. 不送卷軸名單、不消耗材料。  
3. 下一階段：點技能欄寫入清單，再考慮 128 新 magic（例如 0x5D）或與 0x5C bit4 搭配；**不要**借用 75 的 8-byte resolve。

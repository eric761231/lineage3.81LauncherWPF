# 更新登入器（LinLauncher）後：要放到「主程式」目錄的檔案

本文說明：修改 **LinLauncher** 專案並建置完成後，應把哪些檔案放到玩家電腦上實際執行登入器的資料夾（以下稱 **主程式目錄**）。

**製作端 vs 玩家端（請先讀）**

| 位置 | 是否需要 `LinLauncher.dat` |
|------|---------------------------|
| **Encoder 所在目錄**（與 `LinEncoder.exe` 同層，用於「產生登入器」） | **需要**。此檔為 **`LinLauncher.Proxy` 建置產物**，當作模板；Encoder 會把它複製成你指定的檔名（如 `lineage381.exe`）。 |
| **玩家電腦上的 `LinLauncher_Environment`**（實際跑 UI 的目錄） | **不需要**。玩家端組態是 **`config.dat`**，不是 `LinLauncher.dat`。 |
| **玩家遊戲根目錄**（可選，若你要一鍵從根目錄啟動） | **不要**放名為 `LinLauncher.dat` 的模板檔。若要用外層啟動器，請使用 Encoder 產生的 **`.exe`**（與模板同內容、不同檔名），而非把製作用 `.dat` 塞給玩家。 |

---

## 1. 主程式目錄是哪裡？

依本專案慣例，登入器本體放在 **`LinLauncher_Environment`** 內（與 `LinLauncher.exe` 同層），例如：

```text
C:\遊戲根目錄\LinLauncher_Environment\
    LinLauncher.exe
    LinLauncher.dll
    …（執行期需要的檔案）
    config.dat          ← 組態；執行 deploy.ps1 時會依 LinEncoder.ini 自動覆寫（見下文）
```

外層 **Proxy**（由 **`LinLauncher.Proxy`** 建置，模板檔名常為 **`LinLauncher.dat`**，Encoder 亦可另存成 `lineage381.exe` 等）僅在「遊戲根目錄」執行時，若包裝尾端長度**恰好為 4728 bytes** 才會覆寫 `LinLauncher_Environment\config.dat`，否則不寫入。  
**真正跑登入器 UI 的是 `LinLauncher_Environment` 內的 `LinLauncher.exe`**。更新登入器程式時，玩家端只需維護該目錄的 publish 整包與 **`config.dat`**，**不必**在玩家端放置製作用的 **`LinLauncher.dat`** 模板檔。

---

## 2. 必備：從建置輸出「整包覆蓋」

建置方式（擇一）：

- **建議**：在專案根目錄執行 **`deploy.ps1`**，會自動 `dotnet publish`、複製到 `EncoderForPartners\LinLauncher_Environment\`，並執行 **`ConfigDatGen`**：讀取 **`EncoderForPartners\LinEncoder.ini`** 的 **`[LauncherMaker]`**，覆寫同目錄下的 **`config.dat`**，使組態加密與目前 **LinLauncher** 程式碼一致（避免沿用舊 `config.dat` 造成金鑰／解密不符）。
- **手動**：對 `LinProj\LinLauncher\LinLauncher.csproj` 執行 Release 的 `dotnet publish`（與 `deploy.ps1` 相同參數：**`win-x64`**、非單一檔）。

**要複製到主程式目錄的內容**＝publish 輸出目錄內的**全部檔案**（建議整個資料夾覆蓋，不要只複製單一 DLL）。

典型會包含（實際以你本機 `publish` 目錄為準）：

| 類型 | 說明 |
|------|------|
| `LinLauncher.exe` | 進入點 |
| `LinLauncher.dll` | 主程式組件 |
| `LinLauncher.deps.json` | 相依性清單 |
| `LinLauncher.runtimeconfig.json` | .NET 執行期設定 |
| `WebView2Loader.dll`（若有） | WebView2 載入器 |
| `runtimes\...`（若有） | WebView2 等原生依賴，**整個 `runtimes` 資料夾請一併複製** |

> **注意**：本專案 LinLauncher 為 **x64**、**Framework-dependent**（非單一 exe），玩家電腦須安裝 **.NET 8 Desktop Runtime（x64）**；若缺少，常見現象是**雙擊後完全沒畫面**。若改為自包含（Self-contained）發行，則 publish 內會多出 runtime，同樣應**整包**複製。

---

## 3. 不必每次随登入器程式更新而覆蓋的檔案（但主程式目錄常需要）

這些通常**不**在 LinLauncher 的 publish 裡，而是遊戲／啟動流程另外放的；更新登入器**程式**時不必刪除它們，除非你有改版：

| 檔案 | 用途 |
|------|------|
| `LauncherDll.dll` | 注入／啟動遊戲用（須與登入器一併部署於同目錄或你專案設定的路徑） |
| `TW13081901.bin`（或實際遊戲主程式檔名） | 遊戲主程式 |
| `config.dat` | 登入器組態（URL、視窗大小等）；多由 **Encoder 打包**或 **Proxy 從包裝 exe 尾端切出** |
| `list.txt` | 選用：本機伺服器清單（遠端 List 失敗或 0 筆時作為後援；亦可僅用本機清單） |

---

## 4. 與 `deploy.ps1` 的對應關係

執行 **`deploy.ps1`** 後：

- **`LinProj\LinLauncher\publish\*`** 會複製到 **`EncoderForPartners\LinLauncher_Environment\`**  
  → 這就是「測試用主程式目錄」的完整內容，與你手動複製到玩家機器的 **LinLauncher_Environment** 應一致。
- **`EncoderForPartners`** 根目錄另有 **Encoder（LinEncoder）**、`LinLauncher.dat` 模板等，屬**製作／打包登入器**用，不是玩家執行登入器時唯一需要的資料夾。

---

## 5. 檢查清單（更新登入器後）

1. 已用 **Release** 完成 **`dotnet publish` LinLauncher**（或跑過 `deploy.ps1`）。
2. 將 **publish 輸出整包**覆蓋到 **`LinLauncher_Environment`**（或你的實際主程式目錄）。
3. 確認 **`runtimes`**（若有）一併複製。
4. 確認玩家電腦已安裝 **.NET 8 Desktop Runtime（x64）**（若為 FDD 發行；一般從官網下載的「x64」即為此）。
5. **`LauncherDll.dll`、遊戲主程式、`config.dat`** 仍存在且路徑正確。

---

## 6. 常見問題

**Q：只覆蓋 `LinLauncher.dll` 可以嗎？**  
**A：** 不建議。`deps.json`、原生 DLL、`runtimes` 隨版本可能變動；**整包覆蓋**最穩。

**Q：主程式目錄（玩家端）要放 `LinLauncher.dat` 嗎？**  
**A：** **不要。** `LinLauncher.dat` 是 **Encoder 製作目錄**裡給「產生登入器」用的**模板**（與 `LinEncoder.exe` 同層），**不屬玩家端部署**。玩家執行登入器只要 **`LinLauncher_Environment`** 內的 **`LinLauncher.exe`** + **`config.dat`**（及 publish 相依檔）。若要在遊戲根放外層捷徑，請用 Encoder 產出的 **`.exe`**（例如 `lineage381.exe`），不要複製製作端 `.dat` 給玩家。

**Q：Encoder 產生的 `lineage381.exe`（或任意自訂檔名）與直接執行 `LinLauncher_Environment\LinLauncher.exe` 有何不同？**  
**A：** Encoder「產生登入器」實際上是**複製**你選的 **`.dat` 模板**（預設為與 **LinEncoder.exe** 同目錄的 **`LinLauncher.dat`**）到輸出檔名；副檔名改成 `.exe` 亦可執行。該模板來自 **`LinProj\LinLauncher.Proxy`** 專案建置產物（建置 **Encoder** 時會先編譯），邏輯為在**遊戲根目錄**執行，再啟動 **`LinLauncher_Environment\LinLauncher.exe`**。若模板過舊，可能錯誤覆寫 `config.dat`。**請在修改 Proxy 後重新 `dotnet publish` Encoder（或執行 `deploy.ps1`）**，再在 Encoder 裡重新「產生登入器」，或手動複製：  
`EncoderForPartners\LinLauncher.dat` → 另存為遊戲根目錄的 **`lineage381.exe`**（覆蓋）。此為**選用**外層啟動器；**不要**把 `.dat` 模板本身當成玩家必備檔案。

**Q：完全開不起來、連視窗都沒有？**  
**A：** 常見原因為（1）未安裝 **.NET 8 Desktop x64**；（2）仍使用舊的 **x86** 建置檔，與本機只裝 x64 執行環境不符。請改部署 **x64** 的 publish 整包，並安裝 [Desktop Runtime x64](https://dotnet.microsoft.com/download/dotnet/8.0)。若程式曾成功啟動，可查看暫存目錄下的 **`LinLauncher_startup.log`**（啟動與嚴重錯誤會附加寫入）。

---

若之後發行模式改成 **單一檔（Single-file）** 或 **自包含**，請以當時 `publish` 目錄內容為準，仍建議**整包**部署到 `LinLauncher_Environment`。
